# スライドSVGテンプレート

`index.html` の `:root` トークンから起こした、社内共通のスライドの「型」。
**毎回ここからコピーして中身を差し替える。ゼロから作らない。**

| ファイル | 用途 |
|---|---|
| `template-cover.svg` | 表紙（濃紺・提案書の1枚目） |
| `template-content.svg` | 本文（見出し＋箇条書き＋数字ボックス＋結論バンド） |
| `template-compare.svg` | 比較（導入前 / 導入後） |

## 決まっていること（変えない）

- **サイズ**：1920 × 1080（16:9）。左右マージン 120px、下マージン 80px。
- **フォント**：`-apple-system, BlinkMacSystemFont, 'Hiragino Sans', 'Hiragino Kaku Gothic ProN', 'Yu Gothic Medium', Meiryo, sans-serif`（サイト本文と同じ）
- **文字サイズの段**：ディスプレイ 116（表紙タイトル・大きい数字）／ スライド見出し 88 ／ 小見出し 34 ／ 本文 28〜30 ／ 注記 22〜24。**この5段以外は使わない。**
  - **見出し88 : 本文30 ＝ 約2.9倍**。この比は動かさない。見出しを小さくすると本文との差が消える。
- **色**（`index.html` の `:root` と同一）

  | 用途 | 値 | トークン名 |
  |---|---|---|
  | 背景 | `#f7f8fa` | `--bg` |
  | 見出し | `#14161f` | `--ink` |
  | **本文** | `#3a3f4d` | `--ink-soft` |
  | 補足 | `#6b7080` / `#9aa3bb` | `--muted` |
  | 濃紺（表紙） | `#1b2a55` | `--navy-deep` |
  | 差し色の赤 | `#ff5757` | `--accent` |
  | 罫線 | `#e6e8ef` | `--line` |

- **青は5段のランプから取る。**単発の青を新しく作らない。

  | 段 | 値 | 使いどころ |
  |---|---|---|
  | 700 | `#213c8d` | 濃紺寄りの面 |
  | 500 | `#2f56c9` | 主役（`--blue`）。見出し罫・箇条書きマーク・数字 |
  | 300 | `#97abe4` | 濃紺の上に置く小見出し・線 |
  | 100 | `#cdd6f2` | 濃紺の上に置く本文・補足 |
  | 50 | `#eef2fc` | 薄い青の面（`--lavender`） |

  表やグラフで色数が足りないときは、**別の色相を足さずにこの段から取る**。
- **本文は黒にしない。** 黒（`#14161f`）はスライド見出しだけ。箇条書き・説明文は `#3a3f4d`。
- **赤は「1枚に1回」だけ。** 置き場所は決まっている。
  - 表紙 → 小見出し（kicker）の下の短い罫
  - 本文 → 強調ボックスの小見出し（`box-label`）の下の短い罫
  - 比較 → 中央の矢印（**このスライドに罫は置かない**）
- **右端の縦帯**：`x=1849〜1920`（幅71px）は空けておき、縦組みで機密表示と年月（`data-edit="sidebar"`）を入れる。本文の要素をここまで伸ばさない。
- **表紙のタイトルは画面の下半分**（1行目のベースライン 624）。上部に置くのはブランドマークだけ。
- **角丸**：カード 20px、小さい面 18px。
- **影**：`feDropShadow dy=3 stdDeviation=9 opacity=0.07`。これ以上強くしない。

## 使い方

1. 使うテンプレートをコピーして `2026-08-19-〇〇様提案-01.svg` のように連番で置く。
2. **`data-edit` が付いた `<text>` の中身だけ書き換える。** 背景の図形・色・サイズには触らない。
3. 直したい時は「`data-edit="title"` の文字を〇〇に」「`box-num` の `font-size` を 96 に」のように**要素と属性を指定する**。作り直しはしない。
4. PDF が必要なら、SVG を並べた HTML を作ってブラウザで印刷（`shiryo/` の配布物と同じ）。プレビューは `preview.html` をブラウザで開く。

## 注意

- **SVG の `<text>` は自動改行しない。** 1行 = 1つの `<text>`。箇条書きの行送りは 80px。
- 長すぎる文はテンプレートが崩れるサイン。**文を短くする**（フォントを小さくして詰め込まない）。
- 見出し88pxは、全角17文字までなら 1800px に収まる。**それを超えたら文を切る。**
- プレビューを Linux 環境でPNG化すると和文が IPAGothic になる。**実際の見た目は Mac で開いた時が正**。

## 型の出どころ

配色の段・余白・見出しと本文の比は、Figmaコミュニティの無料テンプレート3本の実測値に合わせた（2026-08-19）。
経緯と実測値は `content/memo/2026-08-18-slide-design.md`。
