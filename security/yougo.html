用語の説明

サイバー攻撃（サイバーアタック）

インターネットやネットワークを通じて、他人のコンピュータやサービスに入り込んだり、止めたり、情報を盗んだり壊したりする行為です。不正アクセス、ランサムウェア、フィッシング、DDoS攻撃などがあります。

中小企業では: 社員が数人の会社でも狙われます。IPA の調査では、中小企業の約2割が2023年度に被害に遭った（可能性が高い）と答えています。

くわしく: 中小企業のサイバー攻撃被害の実態

サイバーセキュリティ

サイバー攻撃からコンピュータ、ネットワーク、データを守ることです。単に「セキュリティ」と言うと警備や防犯も含みますが、サイバーセキュリティはネットとITの守りを指します。

くわしく: サイバーセキュリティ対策チェックリスト

情報セキュリティの3要素（CIA）（機密性・完全性・可用性）

機密性（見てよい人だけが見られる）、完全性（勝手に書き換えられていない）、可用性（使いたいときに使える）の3つです。情報セキュリティは、この3つを保つことと説明されます。

脆弱性（ぜいじゃくせい）

ソフトや機器、設定にある、攻撃に使われてしまう弱点です。メーカーが修正版（パッチ）を出したら、適用するまでは弱点が残ります。

中小企業では: 古いままのサイトのソフトや VPN 機器が、そのまま入口になります。

くわしく: VPN機器の脆弱性診断

脆弱性診断（セキュリティ診断）

サイトや機器に、既に知られている弱点が残っていないかを一覧で確かめる検査です。ツールによる自動診断と、専門家による手動の診断があります。

中小企業では: 外に公開しているサイトや機器があれば、年1回以上は受けるのが目安です。

くわしく: 脆弱性診断の費用相場

ペネトレーションテスト（侵入テスト・疑似攻撃）

許可を得たうえで、実際の攻撃と同じ手順で、外から本当に中まで入れるかを試す検査です。脆弱性診断が「弱点の一覧」なら、ペネトレーションテストは「その弱点で本当に入れるか」を確かめます。

くわしく: ペネトレーションテストの依頼先と費用

ハッキングとクラッキング（ホワイトハッカー）

ハッキングはもともと、コンピュータを深く理解して使いこなすことを指す言葉です。他人のシステムに不正に入り込む行為は、区別してクラッキングと呼ばれます。許可を得て、守る側のために攻撃の手順で調べる人を、ホワイトハッカーと呼ぶことがあります。

くわしく: ホワイトハックとは

マルウェアとウイルス

マルウェアは、悪意のあるソフトの総称です。コンピュータウイルスはその一種で、ほかのファイルに入り込んで広がるものを指します。ほかに、ワーム、トロイの木馬、スパイウェア、ランサムウェアなどがあります。

ランサムウェア

パソコンやサーバーのデータを暗号化して使えなくし、元に戻す代わりに身代金を求めるマルウェアです。最近は、データを盗んだうえで「払わなければ公開する」と脅す二重脅迫が多くなっています。

中小企業では: 警察庁によると、2025年の被害報告226件のうち約6割が中小企業でした。

くわしく: ランサムウェア対策の相談先

エモテット（Emotet）

メールの添付ファイルなどから感染し、感染したパソコンからメールのやり取りを盗んで、実際の返信を装ったメールで広がるマルウェアです。IPA が注意を呼びかけています。

フィッシング

銀行や通販、取引先などを装ったメールや SMS で偽のサイトに誘い、ID やパスワード、カード番号を入力させて盗む手口です。

くわしく: ビジネスメール詐欺の対策

ビジネスメール詐欺（BEC）

取引先や社長を装ったメールで、偽の振込先にお金を振り込ませる詐欺です。

中小企業では: 振込先の変更は、電話など別の手段で確かめることが基本です。

くわしく: ビジネスメール詐欺（BEC）の対策

標的型攻撃（標的型メール）

特定の会社や人を狙って、業務に関係があるように見せたメールを送り、添付ファイルやリンクから感染させる攻撃です。

不正アクセス

許可なく他人の ID・パスワードを使ったり、弱点を突いたりして、システムに入り込むことです。日本では不正アクセス禁止法で禁じられています。

くわしく: 退職者のアカウント削除

ファイアウォール

ネットワークの出入口で、許可した通信だけを通し、それ以外を止める仕組みです。パソコンに入っているものと、ネットワーク機器として置くものがあります。

UTM（統合脅威管理）

ファイアウォール、ウイルス対策、不正侵入の検知・防御、Webフィルタなど、複数の守りを1台にまとめたネットワーク機器です。

中小企業では: 1台で複数の守りを入れられるため、中小企業でよく使われます。UTM 自体のファームウェアも更新が必要です。

IDS と IPS（侵入検知・侵入防御）

IDS（侵入検知システム）は、怪しい通信を見つけて知らせる仕組み、IPS（侵入防御システム）は、見つけた怪しい通信を止めるところまで行う仕組みです。

WAF（ウェブアプリケーションファイアウォール）

Webサイトへの攻撃（入力欄からの不正な命令など）を見分けて止める仕組みです。通常のファイアウォールが通信の出入口を見るのに対して、WAF はサイトへのリクエストの中身を見ます。

中小企業では: 問い合わせフォームや会員ページのあるサイトでは、選択肢になります。

くわしく: サイトの改ざん対策

VPN

インターネット上に、社内とつながる専用の通り道を作る仕組みです。テレワークや拠点間の接続で使われます。

中小企業では: VPN 機器はランサムウェアの侵入口になりやすく、2025年の被害では侵入経路の6割以上が VPN 機器でした（警察庁）。

くわしく: VPN機器の脆弱性診断

EPP と EDR

EPP は、ウイルス対策ソフトのように、マルウェアが入るのを防ぐ仕組みです。EDR は、入られたあとの怪しい動きを見つけて、調べたり隔離したりする仕組みです。

くわしく: セキュリティ顧問・SOC・運用代行の比較

XDR

パソコンだけでなく、メール、ネットワーク、クラウドなど複数の場所の記録をまとめて見て、攻撃を見つけて対応する仕組みです。EDR の範囲を広げたものです。

MDR

EDR などの記録を、専門の会社が代わりに見張り、異常があれば対応するサービスです。社内に見る人がいない会社向けです。

くわしく: セキュリティ顧問・SOC・運用代行の比較

NDR

ネットワークを流れる通信を見て、怪しい動きを見つける仕組みです。パソコンに入れなくても、ネットワーク側から見られます。

SOC（セキュリティオペレーションセンター）

機器やソフトの記録を常に見張り、攻撃を見つけて知らせる組織やサービスです。

くわしく: SOC・運用代行の比較

SIEM

いろいろな機器やソフトの記録（ログ）を1か所に集めて、まとめて分析する仕組みです。SOC が見張りに使う道具の1つです。

CSIRT（シーサート）

社内でセキュリティの事故が起きたときに対応するチームです。SOC が見張り、CSIRT が対応する、という分担で説明されることがあります。

中小企業では: 小さな会社では、事故のときに誰が何をするかを決めておくことが、CSIRT の代わりになります。

くわしく: サイバー攻撃を受けたら

ゼロトラスト

社内のネットワークだから安全、と考えず、すべてのアクセスをその都度確かめる考え方です。

SASE と SSE（サシー）

SASE は、ネットワークの機能とセキュリティの機能をクラウドでまとめて提供する仕組みです。SSE は、そのうちセキュリティの部分だけを指します。ゼロトラストを実現する方法の1つです。

ASM（アタックサーフェスマネジメント）

外から見える自社の資産（サイト、サブドメイン、公開している機器など）を洗い出し、弱点を継続して確かめることです。

くわしく: ASM診断とサブドメイン乗っ取り

多要素認証と二段階認証（MFA）

多要素認証は、パスワード（知っているもの）に加えて、スマートフォン（持っているもの）や指紋（体の特徴）など、種類の違う要素を組み合わせて本人を確かめる方法です。二段階認証は確認を2回行うことで、2回とも同じ種類の要素だと多要素認証にはなりません。

くわしく: Microsoft 365・Google Workspace の設定

パスキー

パスワードの代わりに、スマートフォンやパソコンの生体認証や画面ロックでログインする仕組みです。偽サイトに入力させて盗む手口が通りにくくなります。

SPF・DKIM・DMARC

メールの送信元が本物かを確かめる3つの設定です。DMARC を強い設定（隔離・拒否）にすると、他人が自社の名前で送った偽メールを、受け取った側で止められます。

中小企業では: 当社の調査では、中小企業・地域の法人の93%が、偽メールを止められない設定でした。

くわしく: 1,571ドメインのDMARC調査

BYOD

社員の私物のパソコンやスマートフォンを、仕事に使うことです。

中小企業では: 私物の端末を仕事に使う場合のルールを決めることは、IPA の自社診断の項目にも入っています。

くわしく: チェックリスト（25項目）

フォレンジック（デジタルフォレンジック）

事故が起きたあと、パソコンやサーバーの記録を調べて、何が起きたか、何が漏れたかを明らかにする調査です。

くわしく: サイバー攻撃を受けたら

ISMS と Pマーク

ISMS（ISO/IEC 27001）は、会社の情報セキュリティの管理の仕組みについての国際規格の認証です。Pマーク（プライバシーマーク）は、個人情報の扱いについての日本の制度です。

くわしく: 情報セキュリティ規程の雛形

SECURITY ACTION（セキュリティアクション）

中小企業が情報セキュリティ対策に取り組むことを自分で宣言する、IPA の制度です。一つ星と二つ星があり、無料です。

中小企業では: デジタル化・AI導入補助金の申請の要件になっています。

くわしく: SECURITY ACTION 二つ星の要件

SCS評価制度

サプライチェーン全体のセキュリティを高めるために、取引先の対策の段階を評価する国の制度です。星3・星4などの段階があります。

くわしく: SCS評価制度とは

CSIRTとは何ですか？

社内でセキュリティの事故が起きたときに対応するチームです。SOC が見張り、CSIRT が対応する、という分担で説明されることがあります。 小さな会社では、事故のときに誰が何をするかを決めておくことが、CSIRT の代わりになります。

ゼロトラストとは何ですか？

社内のネットワークだから安全、と考えず、すべてのアクセスをその都度確かめる考え方です。

SASE と SSEとは何ですか？

SASE は、ネットワークの機能とセキュリティの機能をクラウドでまとめて提供する仕組みです。SSE は、そのうちセキュリティの部分だけを指します。ゼロトラストを実現する方法の1つです。

ASMとは何ですか？

外から見える自社の資産（サイト、サブドメイン、公開している機器など）を洗い出し、弱点を継続して確かめることです。

多要素認証と二段階認証とは何ですか？

多要素認証は、パスワード（知っているもの）に加えて、スマートフォン（持っているもの）や指紋（体の特徴）など、種類の違う要素を組み合わせて本人を確かめる方法です。二段階認証は確認を2回行うことで、2回とも同じ種類の要素だと多要素認証にはなりません。

パスキーとは何ですか？

パスワードの代わりに、スマートフォンやパソコンの生体認証や画面ロックでログインする仕組みです。偽サイトに入力させて盗む手口が通りにくくなります。

SPF・DKIM・DMARCとは何ですか？

メールの送信元が本物かを確かめる3つの設定です。DMARC を強い設定（隔離・拒否）にすると、他人が自社の名前で送った偽メールを、受け取った側で止められます。 当社の調査では、中小企業・地域の法人の93%が、偽メールを止められない設定でした。

BYODとは何ですか？

社員の私物のパソコンやスマートフォンを、仕事に使うことです。 私物の端末を仕事に使う場合のルールを決めることは、IPA の自社診断の項目にも入っています。

フォレンジックとは何ですか？

事故が起きたあと、パソコンやサーバーの記録を調べて、何が起きたか、何が漏れたかを明らかにする調査です。

ISMS と Pマークとは何ですか？

ISMS（ISO/IEC 27001）は、会社の情報セキュリティの管理の仕組みについての国際規格の認証です。Pマーク（プライバシーマーク）は、個人情報の扱いについての日本の制度です。

SECURITY ACTIONとは何ですか？

中小企業が情報セキュリティ対策に取り組むことを自分で宣言する、IPA の制度です。一つ星と二つ星があり、無料です。 デジタル化・AI導入補助金の申請の要件になっています。

SCS評価制度とは何ですか？

サプライチェーン全体のセキュリティを高めるために、取引先の対策の段階を評価する国の制度です。星3・星4などの段階があります。

IDSとIPSの違いは何ですか？

IDS は怪しい通信を見つけて知らせるだけ、IPS は見つけた通信を止めるところまで行います。

EDRとXDRの違いは何ですか？

EDR はパソコンなどの端末の動きを見て攻撃を見つけます。XDR は端末に加えて、メール、ネットワーク、クラウドなど複数の場所の記録をまとめて見ます。

UTMとファイアウォールの違いは何ですか？

ファイアウォールは許可した通信だけを通す仕組みです。UTM はファイアウォールに、ウイルス対策や不正侵入の防御などを加えて1台にまとめた機器です。

WAFとファイアウォールの違いは何ですか？

ファイアウォールは通信の出入口で通す・止めるを決めます。WAF は Webサイトへのリクエストの中身を見て、入力欄からの不正な命令などの攻撃を止めます。

ハッキングとクラッキングの違いは何ですか？

ハッキングはもともとコンピュータを深く理解して使いこなすことを指し、他人のシステムに不正に入り込む行為はクラッキングと呼んで区別します。

SOCとCSIRTの違いは何ですか？

SOC は記録を常に見張って攻撃を見つける役割、CSIRT は事故が起きたときに社内で対応する役割として説明されることが多いです。
