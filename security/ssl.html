SSL証明書の有効期限が短くなる｜2026年3月から200日、2029年には47日。期限切れで起きることと、今やること

2026 / 11 / 24AIdollargame 編集部読了 約6分
この記事の立場を先に書きます。書いているのは、社内にセキュリティ担当がいない会社に代わってサイト・メール・VPN機器の穴を見つけて直す「ホワイトハック」を提供している株式会社AIdollargameです。比較表には当社も入れています。各社の説明は公式サイト・公式発表に書いてある事実だけに限り、順位や評価は付けていません。

SSL/TLSのサーバー証明書の有効期間は、2026年3月15日から段階的に短くなっています。ブラウザと認証局が決める業界ルール（CA/Browser Forum の Ballot SC-081）によるもので、2029年3月15日以降は最長47日になります。期限が切れると、ブラウザは「安全ではありません」と表示し、お客様はサイトに入れなくなります。

証明書の有効期間の短縮スケジュール（SC-081）

発行日最大有効期間ドメイン認証の再利用期間
2026年3月15日より前398日398日
2026年3月15日〜200日200日
2027年3月15日〜100日100日
2029年3月15日〜47日10日

CA/Browser Forum の投票（2025年4月）と Baseline Requirements による。認証局の票は賛成25・反対0、Apple・Google・Microsoft・Mozilla は全員賛成でした。

国内の認証局の対応（公式の案内）

  • GMOグローバルサイン: 2026年3月14日から最大有効期間を199日に短縮。1年契約では199日の証明書を2枚渡し、2枚目は追加料金なし。2026年12月5日以降に認証したドメインの認証情報は、認証から99日後までしか再利用できません。
  • DigiCert: 2026年2月25日から最大199日。契約期間内の再発行は無償。
  • JPRS: 2026年2月18日以降の発行分は、有効期間を「発行月の5か月後の月末まで」に短縮。自動契約更新タイプを新設。
  • Let's Encrypt（無料の証明書）: 今の90日から、2027年2月10日に64日、2028年2月16日に45日に短縮すると発表しています。

期限切れで実際に起きたこと

株式会社ファインデックスは2026年4月、コーポレートサイトの証明書が期限切れになり、4月5日から4月7日まで警告が表示されたと発表しました。原因は「外部委託先への更新依頼時における確認工程の不備」です。更新を外に頼んでいる会社ほど、期限を自社でも把握しておく必要があります。

自動更新・期限の監視のサービス（公式の料金）

  • Let's Encrypt: 無料。取得と更新を自動化。
  • Cloudflare: 証明書は自動で更新。Free 0ドル、Pro 月20ドル（年払い）。
  • AWS Certificate Manager: エクスポートしない証明書は追加料金なし。
  • はてな Mackerel: 外形監視の中に証明書の期限の監視。スタンダード 最低月2,180円（税込）。
  • UptimeRobot: SSLの期限監視。Solo 月10ドル。

今やること

  1. 自社のサイト・サブドメインの証明書を一覧にし、それぞれの期限と更新の担当を書く。
  2. 使っている認証局・レンタルサーバーが、短縮と自動更新にどう対応するかを確かめる。
  3. 手で更新しているものは、自動更新（ACME）に切り替えられないか相談する。
  4. 期限の監視を入れる。更新を外に頼んでいても、自社にも通知が来るようにする。

よくある質問

SSL証明書の有効期限は、いつから短くなりますか？

CA/Browser ForumのBallot SC-081により、2026年3月15日以降に発行する証明書は最大200日、2027年3月15日以降は100日、2029年3月15日以降は47日になります。

SSL証明書の期限が切れるとどうなりますか？

ブラウザが警告を出します。Appleの説明では、Safariは証明書の期限が切れているか有効でない場合に「安全ではありません」「この接続は安全ではありません」などと表示します。

証明書の期限短縮に、中小企業は何をすればいいですか？

自社のサイトとサブドメインの証明書を一覧にして期限と担当を決め、使っている認証局やレンタルサーバーの対応を確かめ、手で更新しているものは自動更新への切り替えを相談し、期限の監視を入れます。

自社の証明書を無料で確かめる方法はありますか？

株式会社AIdollargameの whitehack.jp にドメインを入れると、証明書の透明性ログから発行されている証明書とサブドメインを無料で洗い出します。相手のサーバーには接続しません。SSL/TLSの設定を詳しく見るにはQualys SSL Labsの無料のテストもあります。
