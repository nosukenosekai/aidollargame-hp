情報セキュリティの規程（ポリシー）は、ゼロから書く必要はありません。IPA（情報処理推進機構）が「中小企業の情報セキュリティ対策ガイドライン」の付録として、基本方針と関連規程のサンプルを Word で無料公開しています。ガイドラインは2026年3月27日に第4.0版に改訂され、付録も第4.0版に揃っています。この記事では、どのファイルを使い、どの順番で作るかを、IPA の本編に書いてある手順どおりにまとめます。

IPA の付録（第4.0版）で使うもの

IPA のページで2026年11月25日に確認。ファイルはすべて無料でダウンロードできます。

付録正式名形式使う場面
付録2情報セキュリティ基本方針（サンプル）Word・1ページ会社としての方針を1枚で宣言する。SECURITY ACTION の二つ星で外部公開が求められる
付録35分でできる！情報セキュリティ自社診断PDF・25項目今の弱いところを25問で洗い出す。二つ星の要件
付録4情報セキュリティハンドブック（ひな形）PowerPoint・17ページ社員に配る「守ること」の冊子
付録5情報セキュリティ関連規程（サンプル）Word・59ページ規程の本体。赤字・青字を自社向けに書き換える
付録6資産管理台帳（サンプル）Excel・9シート守る情報と機器の一覧。リスク値の計算シート付き
付録7中小企業のためのクラウドサービス安全利用の手引きPDF・8ページクラウドを使っている会社
付録8中小企業のためのセキュリティインシデント対応の手引きPDF・8ページ事故が起きたときの手順

第4.0版では、それまでの「5か条」に「バックアップを取ろう!」が加わって「情報セキュリティ6か条」になりました。自社診断にも「外部から内部ネットワークへの不要な通信を遮断する」「ウェブサイトを安全に運用する」などの項目が加わっています。検索で古い版（第3.1版など）のファイルが出てきたら、IPA のページから第4.0版を取り直してください。

作る順番（IPA の本編どおり）

  1. STEP1：「情報セキュリティ6か条」に取り組む（OS・ソフトを最新に、ウイルス対策ソフト、パスワードの強化、共有設定の見直し、バックアップ、手口を知る）。
  2. STEP2：付録3の自社診断で弱いところをつかみ、付録2を参考に基本方針を作る。IPA は基本方針に「決まった書き方はありません」としています。
  3. STEP3：体制を決め、守るべき情報とリスクを特定してから、付録5を参考に規程を作る。IPA は「サンプル文中の赤字、青字部分を自社向けに書き換えれば規程が完成します」と書いています。
  4. STEP4：外部の専門家を交えてリスク分析をする（付録6の「リスク値算定」シート）。

59ページの規程を最初から全部埋めようとすると止まります。STEP2 の基本方針1枚と自社診断25問までなら、半日で終わる量です。

SECURITY ACTION と補助金

  • 一つ星：「情報セキュリティ6か条」に取り組むと宣言する。対策を実施する前でも申し込めます。
  • 二つ星：自社診断（25問）を実施し、基本方針を作って外部に公開する。公開方法は、自社サイトへの掲載、会社案内やパンフレットへの掲載、その他から選びます。
  • デジタル化・AI導入補助金2026（旧 IT導入補助金）では、一つ星か二つ星の宣言が申請の要件です。セキュリティ対策推進枠の公募要領では、二つ星の宣言が審査の加点項目に入っています。
  • IPA の補助金向けページによると、2026年3月以前の自己宣言は交付申請に使えません。補助金の申請に使う GビズID で、SECURITY ACTION の管理システムから申し込む必要があります。

作ったあとに、外から確かめること

規程に「ソフトを最新に保つ」「不要な通信を遮断する」と書いても、実際にサイトや VPN 機器が最新かどうかは、規程だけでは分かりません。取引先のチェックシートでも、規程の有無と並んで、実際にやっているかを聞かれます。

よくある質問

情報セキュリティ規程の雛形はどこで手に入りますか？

IPA（情報処理推進機構）の「中小企業の情報セキュリティ対策ガイドライン」第4.0版の付録として、無料で公開されています。付録2が情報セキュリティ基本方針（サンプル、Word・1ページ）、付録5が情報セキュリティ関連規程（サンプル、Word・59ページ）です。

IPAのガイドラインの最新版は何版ですか？

2026年3月27日に公開された第4.0版です。5か条に「バックアップを取ろう!」が加わって「情報セキュリティ6か条」になり、自社診断の項目が増え、SCS評価制度の考え方が取り込まれました。

情報セキュリティ基本方針と規程は何が違いますか？

基本方針は、会社として情報セキュリティにどう取り組むかを宣言する1枚の文書で、SECURITY ACTION の二つ星では外部への公開が求められます。規程は、その方針を実行するための具体的な決まり（誰が何をどう扱うか）です。IPA は、基本方針を先に作り、体制とリスクを決めてから規程を作る順番を勧めています。

SECURITY ACTIONの二つ星には何が必要ですか？

「5分でできる！情報セキュリティ自社診断」（25問）を実施することと、情報セキュリティ基本方針を作って外部に公開することの2つです。基本方針は IPA の付録2を基にしても、自作してもかまいません。

補助金の申請にSECURITY ACTIONは必要ですか？

デジタル化・AI導入補助金2026では、一つ星か二つ星の宣言が要件です。IPA の案内では、2026年3月以前の自己宣言は交付申請に使えず、補助金の申請に使う GビズID で申し込む必要があります。
