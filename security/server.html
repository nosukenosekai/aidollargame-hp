ドメインのDNSを別の会社で管理している場合

多くの事業者は、管理画面で設定しても、DNSを他社で管理している場合はそちらに自分で登録する必要があると書いています（さくら、お名前.com、KAGOYA、ConoHa WING、カラフルボックスなど）。ヘテムルは他社DNSでの設定方法を「サポート対象外」としています。SPFは1つのドメインに1行にまとめます。当社の調査では、SPFを2行置いてしまっている（どちらも無効になる）ドメインが0.9%ありました。

進め方

  1. 使っている事業者のヘルプで、SPF・DKIMが入っているかを確かめる。
  2. DMARC を p=none（何もしない）で入れ、レポートの送り先を指定する。
  3. レポートで、自社の名前で送っている仕組み（会計ソフト・予約システム・配信サービスなど）を全部洗い出す。
  4. 漏れが無いことを確かめてから、quarantine（迷惑メール）、reject（配送しない）と上げる。

自分で触るのが不安な場合は、設定代行の比較にDNSへの書き込みまで代行する会社をまとめました。

よくある質問

エックスサーバーでDMARCはどこで設定しますか？

エックスサーバーの公式マニュアルによると、サーバーパネルの「DMARC設定」で、対象ドメインの編集ボタンから設定します。ポリシーは「何もしない」「迷惑メールとして配送する」「メールを配送しない」から選び、レポート通知先も指定できます。

ロリポップでDMARCの設定は必要ですか？

ロリポップの公式ヘルプでは、ロリポップのDNSを使っている場合はDMARCの設定は不要としています。ムームーDNSを使っている場合は、_dmarc にTXTで v=DMARC1; p=none; を手で入れるよう案内しています。

お名前.comのレンタルサーバーでDMARCを設定するには？

お名前.comのレンタルサーバー（RS）では、初期でSPFとDKIMが設定されていますが、DMARCは入っていません。コントロールパネルの「メールセキュリティ」で「DMARC 認証設定」をONにします。共用サーバーSDとお名前メール（ライト/スタンダード）はDKIMとDMARCに対応していません。

Google WorkspaceやMicrosoft 365でDMARCはどこで設定しますか？

どちらも管理画面にDMARCの設定画面は無く、ドメインのDNSに _dmarc のTXTレコードを自分で入れます。両社とも p=none から始めて段階的に上げるよう勧めています。
