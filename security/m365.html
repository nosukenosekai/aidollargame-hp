警察庁・総務省・経済産業省が2026年3月12日に公表した資料には、IPA に届いた2025年の不正アクセスの届出について「インターネットサービス（Microsoft 365 等）アカウントを乗っ取られたことによる不正メールの送信被害等が見られた」と書かれています。被害の原因で最も多かったのは「ID・パスワード管理の不備」でした。この記事では、Microsoft 365 と Google Workspace で、追加の費用なしに入れられる設定を、両社の公式ヘルプからまとめます。

Microsoft 365：セキュリティの既定値群

Microsoft の「セキュリティの既定値群（Security defaults）」は、追加の費用なしで使える設定のまとまりです。ON にすると次の6つが入ります。

  1. 全ユーザーに多要素認証（MFA）の登録を必須にする
  2. 管理者には毎回 MFA を求める
  3. 必要なときにユーザーに MFA を求める
  4. レガシー認証（古い接続方式）をブロックする
  5. デバイスコードフローをブロックする
  6. Azure portal など、特権の要る操作を守る

2019年10月22日以降に作ったテナントでは、既定で ON になっている可能性があります。Microsoft の分析では、資格情報スタッフィング攻撃の97%以上、パスワードスプレー攻撃の99%以上がレガシー認証を使っています。条件付きアクセス（Entra ID P1 以上の有料ライセンスが必要）を使っていない会社は、まずこの既定値群が ON かを確かめます。

Microsoft 365：管理者と外部共有

  • 管理者アカウントの数を絞り、普段の仕事は管理者でない通常のアカウントで行う。管理者専用のアカウントにはライセンスが要りません。
  • 誰にも割り当てない緊急用の管理者アカウントを2つ以上持つ（16文字以上のパスワード）。
  • SharePoint・OneDrive の外部共有を、「すべてのユーザー」「新規および既存のゲスト」「既存のゲスト」「組織内のユーザーのみ」の4段階から選ぶ。「すべてのユーザー」のリンクには有効期限を付けられます。

Google Workspace：2段階認証と共有

  • 2段階認証の強制：管理コンソールの［セキュリティ］→［認証］→［2段階認証プロセス］で、「今すぐ強制」か日付を指定して適用します。使わせる方法は「制限なし」「SMS・音声以外」「セキュリティキーのみ」から選べます。
  • Google の小規模ビジネス（1〜100人）向けチェックリストは、管理者と主要ユーザーへの2段階認証の義務付け、特権管理者を複数作る、新しく作ったファイルのリンク共有をオフにする、社外と共有するときに警告を出す、社外とのカレンダー共有を制限する、などを挙げています。
  • 100人超向けのチェックリストは、「安全性の低いアプリ」へのアクセスのブロックと、外部共有をドメイン内に絞ることも挙げています。
  • 設定を一覧で見られる「セキュリティの状況」ページは、Enterprise などの上位版向けで、Business プランは対象に入っていません。Business プランの会社は、上のチェックリストを1つずつ確かめます。

アカウントの外側：自社のドメイン

アカウントを守っても、自社のドメインに DMARC が入っていないと、他人が貴社の名前でメールを送れます。当社が中小企業・地域の法人1,571ドメインを調べたところ、メールに Google Workspace を使っていたのは9.2%、Microsoft 365 は3.5%で、DMARC を入れていたのは全体の45.7%でした（調査）。両社とも管理画面に DMARC の設定画面は無く、DNS に自分で書き足します（設定場所の一覧）。

よくある質問

Microsoft 365のセキュリティの既定値群とは何ですか？

追加の費用なしで使える Microsoft の設定のまとまりです。全ユーザーの多要素認証の登録の必須化、管理者への毎回の多要素認証、レガシー認証のブロック、デバイスコードフローのブロックなどが入ります。条件付きアクセス（有料の Entra ID P1 以上）を使っていない会社向けです。

Google Workspaceで2段階認証を全員に強制するには？

管理コンソールの［セキュリティ］→［認証］→［2段階認証プロセス］で「今すぐ強制」か、日付を指定して適用します。新しいユーザーには1日〜6か月の登録期間を設定できます。

レガシー認証をブロックする理由は？

Microsoft の分析では、資格情報スタッフィング攻撃の97%以上、パスワードスプレー攻撃の99%以上がレガシー認証を使っています。レガシー認証では多要素認証がかからないためです。

Microsoft 365やGoogle WorkspaceでDMARCは自動で入りますか？

入りません。両社とも管理画面に DMARC の設定画面は無く、ドメインの DNS に _dmarc の TXT レコードを自分で入れます。
