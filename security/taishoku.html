退職者のアカウント削除｜元従業員の不正アクセスは2025年に61件。Microsoft 365・Google Workspaceで止める手順と、退職日の確認一覧

この記事の立場を先に書きます。書いているのは、社内にセキュリティ担当がいない会社に代わってサイト・メール・VPN機器の穴を見つけて直す「ホワイトハック」を提供している株式会社AIdollargameです。比較表には当社も入れています。各社の説明は公式サイト・公式発表に書いてある事実だけに限り、順位や評価は付けていません。

警察庁・総務省・経済産業省が2026年3月12日に公表した資料によると、2025年に検挙された、ID とパスワードを使う型の不正アクセス399件のうち61件は「識別符号を知り得る立場にあった元従業員や知人等による犯行」でした（2024年は107件）。辞めた人の ID が生きたままだと、その人は辞めた翌日も社内のシステムに入れます。この記事では、退職者のアカウントを止める手順を、Microsoft 365 と Google Workspace の公式ヘルプからまとめます。

退職後の ID で入られた例

  • 泉佐野市の医療機関（2026年）：3月9日まで勤めた元医師が、3月15日と19日に在職中の ID で電子カルテに入ったとして、7月15日に大阪府警が再逮捕。患者約50人分が見られる状態だったと報じられています。
  • 熊本市のイベント会社（2026年）：元従業員が2025年4月に元勤務先のシステムに複数回入り、企画の文書を消した疑いで、6月24日に熊本県警が逮捕したと報じられています。
  • NTTマーケティングアクトProCX（2024年）：保守業務をしていた元派遣社員が、システム管理者のアカウントで顧客情報約928万件を持ち出しました。

IPA の「組織における内部不正防止ガイドライン」（第5版）は、「異動又は退職により不要となった利用者 ID 及びアクセス権は、ただちに削除しなければならない」と書いています。ID を消すとアクセス記録も消える場合は、ID をロックして記録を残すよう注記しています。

Microsoft 365 で止める手順（公式の7手順）

  1. サインインをブロックし、パスワードをリセットして「すべてのセッションからサインアウト」する。サインインのブロックは反映まで最大24時間かかるので、すぐ止めたいときはパスワードのリセットを先にやります。
  2. メールボックスの中身を残す。
  3. 会社の情報が入ったスマートフォンなどをワイプする。
  4. メールを別の人に転送するか、共有メールボックスに変える。
  5. OneDrive と Outlook のデータを他の社員に渡す。
  6. ライセンスを外す。外すと、メール・連絡先・予定表は30日後に完全に消えます。
  7. アカウントを削除する。

Exchange 側で、Outlook・Web 版・ActiveSync・IMAP・POP3 の接続もオフにします。古い接続方式が開いていると、パスワードを変えるまで入れる場合があるためです。

Google Workspace で止める手順

  • 停止：管理コンソールの［ディレクトリ］→［ユーザー］→［ユーザーを停止］。全サービスに入れなくなり、データは残ります。停止中のアカウントも課金の対象です。
  • データの移管：メールとドライブのファイルのオーナーを、他の社員に移します。
  • アーカイブユーザーライセンス：データを残したまま、アカウントを使えない状態にする有料のライセンスです。
  • 削除：移管しなかったデータは消えます。削除から20日以内なら復元できます。

退職日に確かめる一覧

  1. メール・グループウェア（Microsoft 365／Google Workspace）のアカウントを止めた
  2. 会計ソフト、給与、ネットバンキング、予約システムなど、クラウドのサービスごとの ID を止めた
  3. サイトの管理画面（WordPress など）、ドメインの管理画面、レンタルサーバーの ID を止めた
  4. VPN の ID を止めた
  5. 退職者が知っていた共用のパスワード（Wi-Fi、共用アカウント）を変えた
  6. 会社の PC・スマートフォン・入館カードを返してもらった
  7. 秘密保持の誓約書をもらった（IPA のガイドラインが雇用終了の手続きとして挙げています）

2〜4は人事の手続きから漏れやすいところです。どのサービスに誰の ID があるかの一覧が無いと、止める対象が分かりません。

よくある質問

退職者のアカウントはいつ削除すべきですか？

IPA の「組織における内部不正防止ガイドライン」は、退職で不要になった利用者 ID とアクセス権は「ただちに削除しなければならない」としています。ID を消すとアクセス記録も消える場合は、ID をロックして記録を残します。

Microsoft 365で退職者のアカウントを止めるには？

Microsoft の公式手順では、サインインのブロックとパスワードのリセット、すべてのセッションからのサインアウトを最初に行います。サインインのブロックは反映まで最大24時間かかるため、すぐ止めたいときはパスワードのリセットを使います。その後、メールとOneDriveのデータを他の社員に渡し、ライセンスを外し、アカウントを削除します。

Google Workspaceで退職者のアカウントを止めるには？

管理コンソールの［ディレクトリ］→［ユーザー］でユーザーを停止すると、全サービスに入れなくなり、データは残ります。停止中も課金の対象です。データを他の社員に移管してから削除すれば、ライセンス料はかかりません。削除から20日以内なら復元できます。

元従業員による不正アクセスはどのくらいありますか？

警察庁・総務省・経済産業省の公表では、2025年に検挙された ID・パスワードを使う不正アクセス399件のうち、元従業員や知人など ID を知り得る立場にあった者による犯行は61件でした（2024年は107件）。
