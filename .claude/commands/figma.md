Figma のコミュニティを見て、自社のスライドテンプレートの参考になるものを探してください。

## 手順

1. **ブラウザ操作の準備**
   - Playwright MCP が使えるか確認する。使えなければ `claude mcp add playwright npx @playwright/mcp@latest` を実行し、
     再起動が必要ならユーザーにそう伝えて一度止まる。

2. **ログイン**
   - Figma のログインが必要な画面に来たら、**ブラウザの画面を出したまま止まり、ユーザーに自分でログインしてもらう。**
   - **パスワード・認証コードをユーザーに入力させようとしない。チャットに書かせない。**

3. **探す**
   - `https://www.figma.com/community/presentations` を開き、`pitch deck` / `presentation` / `proposal` で探す。
   - 無料のものに絞る。

4. **報告**
   - 良さそうなものを3つ選び、それぞれについて次を具体的に書く。
     - 配色（実際の色を16進数で。何色使っているか）
     - 余白の取り方（左右マージン、要素間の間隔の目安）
     - 見出しと本文のサイズ差（何倍か）
     - 表紙の構成（要素の並び）
   - **「オシャレ」「洗練された」のような感想は書かない。数値と構造だけを書く。**

## 前提

- 自社の型は `content/slides/`（`README.md` に仕様、`template-*.svg` が実物）。
  **これを置き換えるのではなく、良いところだけ移植する**のが目的。配色とロゴは自社のものを保つ。
- 背景は `content/memo/2026-08-18-slide-design.md` にある。
