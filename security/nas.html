NASのランサムウェア対策｜Synologyが2026年10月に攻撃を発表。メーカー5社の公式の対策と、今すぐ確かめる5つ

この記事の立場を先に書きます。書いているのは、社内にセキュリティ担当がいない会社に代わってサイト・メール・VPN機器の穴を見つけて直す「ホワイトハック」を提供している株式会社AIdollargameです。比較表には当社も入れています。各社の説明は公式サイト・公式発表に書いてある事実だけに限り、順位や評価は付けていません。

Synologyは2026年10月29日、古いDSM（NASの基本ソフト）を狙ったランサムウェア攻撃が実際に起きていると発表しました。悪用されているのは、2024年12月に修正済みの脆弱性（Synology-SA-24:20、CVE-2024-10441など、CVSS 9.8）です。更新していないNASが狙われています。

メーカー公式のランサムウェア対策

メーカー公式の案内の要点
Synologyすぐに更新し、自動更新を有効にする（2026年10月29日）。既定の admin を無効にし新しい管理者を作る、強いパスワード、自動ブロック、2段階認証、不要な公開ポートを閉じる、書き換えできないスナップショット
QNAPNASをインターネットに直接出さない、管理用ポートの転送とUPnPを止める、外から使うならVPN、ファームとアプリを更新、不要なアカウントとアプリを削除、スナップショット
バッファロー初期・弱い管理者パスワードをすぐ変える（2025年6月27日）。TeraStationの一部で、指定期間は削除も変更もできない不変スナップショット（2025年3月、無料）
アイ・オー・データ外付けHDDにオフラインでバックアップ、世代は14世代を推奨。LAN DISK用のウイルス対策アドオン（2025年10月）
ASUSTORパスワードを強くする、既定のポートを変える、使わないSSH・SFTPを止める、3-2-1バックアップ、更新（2024年3月）

今すぐ確かめる5つ

  1. NASの基本ソフトが最新か（Synologyなら DSM 7.2.2-72806-1 以降が SA-24:20 の修正版）。
  2. NASの管理画面やファイル共有が、インターネットから開ける状態になっていないか（ポート転送・UPnP・リモートアクセス機能）。
  3. 既定の admin が残っていないか、パスワードは強いか、2段階認証は入っているか。
  4. スナップショットが取れているか。書き換えできない設定にできるか。
  5. NASとは別の場所（外付けHDDのオフライン、クラウド）にもバックアップがあるか。

よくある質問

NASのランサムウェア対策は何をすればいいですか？

メーカー各社の公式の案内では、基本ソフトの更新、NASをインターネットに直接出さない（ポート転送・UPnPを止める）、既定の管理者アカウントの無効化と強いパスワード・2段階認証、書き換えできないスナップショット、NASとは別の場所へのバックアップが挙げられています。
