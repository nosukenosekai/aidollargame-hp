SCS評価制度とは｜星3・星4の違い、2027年3月の受付開始、中小企業がやること（2026年11月時点）

この記事の立場を先に書きます。書いているのは、社内にセキュリティ担当がいない会社に代わってサイト・メール・VPN機器の穴を見つけて直す「ホワイトハック」を提供している株式会社AIdollargameです。比較表には当社も入れています。各社の説明は公式サイト・公式発表に書いてある事実だけに限り、順位や評価は付けていません。

経済産業省とIPAは、取引先のセキュリティ対策を共通の基準で評価する「サプライチェーン強化に向けたセキュリティ対策評価制度（SCS評価制度）」を準備しています。IPAは、星3と星4の申請受付を2027年3月に始める予定としています。取引先ごとにばらばらだったセキュリティのチェックシートが、この制度の星で置き換わっていく可能性があります。

IPAの詳細情報ページ、よくある質問、料金設定のお知らせ（2026年9月18日）による。星5は要求事項・開始時期とも検討中です。

誤解されやすい点（IPA・経済産業省の説明）

  • 取得は任意で、取引の要件にするかは当事者同士で決めます。業種・規模は問いません（よくある質問 A1-2・A1-3）。
  • 全てを満たしていなくても、それだけで直ちに取引停止を求めるものではありません（A1-4）。
  • 特定のセキュリティ製品の導入は必須ではありません（A2-5）。
  • 経済産業省は2026年4月27日、「取得していないと商取引が規制される」「今すぐ取得しないと入札から除外される」といった勧誘が報告されているとして、注意を呼びかけています。

外に公開しているシステムに関わる要求事項

要求事項（Ver1.1、2026年10月28日）のうち、インターネットに公開しているサーバや機器に関わるものを挙げます。IPAの解説書は、公開サーバ（Webサーバ、メールサーバなど）を適用範囲に必ず含めるとしています。

  • 星3 4-4-4-2: 重大・高リスク、またはCVSS 7.0以上の脆弱性を直す更新を、公開から14日以内に当てる。インターネットとの境界にあるネットワーク機器のOSとファームウェアも対象。
  • 星3 4-4-4-1: サポートが切れた製品は削除するか、インターネットから切り離す。
  • 星3 4-5-1: ファイアウォールやルータの初期パスワードを変え、認証されていない外からの通信を遮断する。
  • 星4 3-2-1: 脆弱性を管理する体制（情報源、判断の基準、残っている脆弱性の把握、月次の点検）。
  • 星4 4-4-4-3: 境界のネットワーク機器に CVSS 7.0以上の脆弱性が無いこと。評価機関の「技術検証」として、外からの脆弱性診断（原則5台）で確かめます。

なお、要求事項と解説書には、SPF・DKIM・DMARC（なりすましメール対策）を求める条文はありません。取引先から個別のチェックシートで聞かれることはあります（チェックシートの回答支援）。

中小企業が使える支援

  • お助け隊サービス（新類型）: 中小企業が星3・星4を取るための診断・改善・申請の支援を1つのパッケージにしたもの。2026年10月〜2027年9月に実証事業（参加無償、15事業者）を行い、2027年度末までに制度にする予定です。
  • SECURITY ACTION: IPAは、星3・星4の準備段階としてまずSECURITY ACTIONの自己宣言から、と案内しています。
  • 価格交渉: 経済産業省と公正取引委員会は、発注側が星の取得にかかる費用について価格交渉に応じることを想定した事例を出しています。

よくある質問

SCS評価制度はいつから始まりますか？

IPAは、星3と星4の申請受付を2027年3月に始める予定としています。経済産業省は2026年度末頃の制度開始を目指すとしています。星5は検討中です。

SCS評価制度の星3と星4の違いは？

星3は全てのサプライチェーン企業が最低限実装すべき対策で、自己評価をSCSセキュリティ専門家が確認します（要求事項26件、有効期間1年、登録料は2028年3月まで1年1万円）。星4は標準的に目指すべき対策で、評価機関が第三者評価をします（要求事項43件、有効期間3年、登録料3年6万円）。

SCS評価制度を取らないと取引が止まりますか？

IPAのよくある質問では、取得は任意で、全てを満たしていなくてもそれだけで直ちに取引停止を求めるものではないとしています。経済産業省は「取得しないと入札から除外される」などの勧誘に注意するよう呼びかけています。

SCS評価制度に脆弱性診断は必要ですか？

星4では、評価機関の技術検証として、インターネットとの境界にあるネットワーク機器（原則5台）に外から脆弱性診断を行い、CVSS 7.0以上の脆弱性が無いかを確かめます。星3に第三者による診断はありませんが、CVSS 7.0以上の脆弱性の更新を14日以内に当てることが求められます。
